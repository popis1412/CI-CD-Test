# 📑 Project: 게임 QA 테스트 분석 및 리포트 자동화

본 프로젝트는 게임 QA 신입 포트폴리오를 목적으로,
공개 자료 기반으로 전투 UI 및 전투 시스템 테스트 케이스를 설계하고,
Excel 수행 결과를 Python으로 집계하여 HTML 리포트로 자동 생성한 프로젝트입니다.

또한 Jenkins Pipeline과 Slack 알림을 구성하여
QA 수행 결과가 팀에 공유되는 기본 흐름을 재현했습니다.

---

## 1. 🎮 테스트 대상 및 QA 전략

### 1) 테스트 대상

MMORPG 전투 화면을 기준으로 다음 요소를 테스트 대상으로 선정했습니다.

* **전투 UI**

  * 캐릭터 HP / MP 바
  * 보스 HP 바
  * 레이드 타이머
  * 파티원 UI
  * 하단 스킬 UI

* **전투 시스템**

  * 스킬 사용 시 자원 변화
  * 타이머 기반 패턴 진행
  * 상태 표시 (버프 / 디버프)

---

### 2) 우선순위 선정 이유

전투 UI는 실제 플레이 경험에 직접적인 영향을 주는 핵심 요소입니다.

| 요소            | 영향        |
| ------------- | --------- |
| HP / MP UI 오류 | 생존 판단 불가  |
| 타이머 오류        | 레이드 실패 가능 |
| 스킬 UI 오류      | 입력 불가     |
| 보스 정보 오류      | 전략 수행 불가  |

---

### 3) 리스크 식별

| 기능      | 주요 리스크           |
| ------- | ---------------- |
| HP/MP 바 | 수치 표시 오류, 갱신 지연  |
| 타이머     | 시간 오차, 초기화 오류    |
| 파티 UI   | 동기화 실패           |
| 스킬 UI   | 입력 누락, 쿨타임 표시 오류 |

---

### 4) 테스트 설계 기준

* 사용자 행동 기반 시나리오 구성
* 정상 / 예외 흐름 모두 포함
* UI 표시 + 기능 동작 동시 검증

---

## 2. 🧪 테스트 데이터 생성 (check_process.py)

Mock 결제 시스템을 통해 실제 사용자 흐름 기반 테스트 데이터를 생성합니다.

### 실행 방법

```bash
python check_process.py
```

### 동작 흐름

1. 서버 실행
2. 웹 페이지 접속 (http://127.0.0.1:5000)
3. 상품 선택 (버튼 클릭)
4. 결제 진행
5. 결제 완료 시 이벤트 발생
6. `result.xlsx` 자동 생성 및 기록

---

### 자동 테스트 항목

| 항목      | 조건             |
| ------- | -------------- |
| 접속      | 페이지 로드 시       |
| 이미지 로드  | 이미지 요청 성공 시    |
| 서버 요청   | POST 200 응답    |
| 버튼 클릭   | 클릭 이벤트 발생      |
| 결제 완료   | purchase 요청 성공 |
| 알림 표시   | alert 발생       |
| 버튼 비활성화 | disabled 상태    |
| 텍스트 변경  | "구매완료" 표시      |
| 재클릭 방지  | 중복 클릭 차단       |

👉 모든 항목은 **초기 False → 이벤트 발생 시 True로 변경**

## 3. 📊 QA 결과 분석 (make_report.py)

Excel 테스트 결과를 기반으로 정량 분석을 수행합니다.

### 실행 방법

```bash
python make_report.py
```

### 기능

* 수행 결과(Pass / Fail / Not Test) 집계
* 카테고리(대분류 / 중분류)별 통계
* 실패 비율 계산
* 결함 리스트 추출
* HTML 리포트 자동 생성
